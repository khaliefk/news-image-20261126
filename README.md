## The image

`entry.png` is a newspaper front page in six panels. The masthead names the
day, and each panel covers one story reported on 26 November 2026:

1. US tariffs plan: Washington prepares new tariffs aimed at factory
   overcapacity, aimed at a host of countries including China.
2. Ukraine strikes airbase: Ukraine says it hit a major Russian air base
   and damaged five planes.
3. North Korea nuclear call: Kim Jong Un calls for wider deployment of
   tactical nuclear weapons.
4. Markets fall: US stocks slide, with the Nasdaq down almost 4% as
   fears over AI valuations spread.
5. Cairo tanker fire: a fuel tanker crash on a Cairo highway sets off a
   huge fire, killing 31 people.
6. Asteroid crater: close-up images from the Hera spacecraft show the
   stadium-sized crater left by the asteroid deflection test.

The image was generated fresh for this entry. No photo or stock image
was used. It is a 1024 by 1024 PNG, 1,018,223 bytes, inside the gate
limits of 1024 by 1024 pixels and 1 MiB.

## How it runs

`main.ts` (Node 22, standard library only) copies `entry.png` to the
output directory. Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
